# Домашнее задание к работе 9

## Условие задачи
Напишите программу, выводящую на экран заданную геометрическую фигуру (прямоугольный треугольник), нарисованную с помощью заданного с клавиатуры символа. Предусмотреть возможность изменения размеров фигуры путем задания ее размеров (угла и катета) пользователем.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Объявить необходимые переменные и константы (число Пи).
3. Организовать цикл для повторного запуска программы (do-while).
4. Запросить у пользователя:
   - `sym` — символ для построения фигуры.
   - `x` — угол в градусах (от 1 до 89).
   - `b` — длину прилежащего катета.
5. Перевести угол из градусов в радианы.
6. Вычислить высоту треугольника `h` (противолежащий катет) по формуле: \(h = b \cdot \tan(x)\).
7. Если высота меньше 1, принять её за 1.
8. Вывести вычисленную высоту (катет `a`).
9. Организовать цикл для построения строк треугольника (от 0 до `h`):
   - Вычислить количество символов `n` в текущей строке (пропорционально высоте).
   - Вывести пробелы для формирования наклона гипотенузы.
   - Вывести заданный символ `n` раз.
   - Перейти на новую строку.
10. Спросить пользователя, хочет ли он продолжить (1 — да, 0 — нет).
11. Если введено не 0, повторить с п. 4.
12. **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <math.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, "Russian");
    const double PI = 3.14159265358979323846;
    int again;
    
    do
    {
        char sym;
        double x;
        int b, r, c;
        
        printf("Введите символ для построения: ");
        scanf(" %c", &sym);
        printf("Введите угол a в градусах (от 1 до 89): ");
        scanf("%lf", &x);
        printf("Введите прилежащий катет b > 0: ");
        scanf("%d", &b);
        int h = (int)(b * tan(x * PI / 180.0) + 0.5);
        if (h < 1) h = 1;
        printf("Катет a = %d симв.\n\n", h);
        for (r = 0; r < h; r++)
        {
            int n = (int)((double)b * (r + 1) / h + 0.5);
            if (n < 1) n = 1;
            for (c = 0; c < b - n; c++)
                putchar(' ');
            for (c = 0; c < n; c++)
                putchar(sym);
            
            putchar('\n');
        }
        
        printf("\nПродолжить? ");
        scanf("%d", &again);
        printf("\n");
        
    } while (again != 0);

    return 0;
}
```
